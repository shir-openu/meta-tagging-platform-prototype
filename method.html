The method, and its limits

← back to the platform  ·  A page written so that you can disbelieve us: what the tool does, what it does not know, and how to reproduce every number it shows.

In one line

We take a contested concept, collect from the literature the rival definitions and the cases the literature asserts are or are not instances of it, and score each definition as though it were a classifier. What is distinctive is not the measurement — that exists in the literature — but that every case is anchored to an exact verbatim quote from a paper, and that the corpus is a parameter you choose.

How the score is computed

Each definition has a verdict on each case: does it admit the case. That is compared with the gold label — what the paper asserts. From there four numbers, TP, FP, FN, TN, and from them MCC.
MCC = (TP·TN − FP·FN) / √((TP+FP)(TP+FN)(TN+FP)(TN+FN))
Why MCC and not F1. About 80% of the cases here are positive. F1 ignores true negatives, so a definition that admits almost everything gets a flattering F1 and a poor MCC. MCC is the one that notices. +1.000 is a perfect match, 0.000 is a coin flip, negative means it falls the opposite way.

The circular control — why there is a deliberately silly definition in the table

One of the definitions is "whatever people call art". It is circular and worthless, and it is there to check us: it copies the answer, so it must score near +1.000 on any corpus. If it scores less, our coding contradicts itself on that corpus and no other number in the table may be read. The tool raises that warning itself.

This is not theoretical. An AI agent given only this site's URL misread the scoring rule, saw the control at 0.608 instead of 0.983, and knew from that alone that its own reading was broken.

What the tool does not know

  • A single coder. The tagging was done in one pass. Two-independent-coder reliability is not met, and we do not claim it is.
  • The confidence intervals overlap at the top. "Among the leaders" is allowed. "The best" is not.
  • Runs are not comparable. We measured that instruction wording alone moves MCC by about 0.12 for an identical definition. A number from one run cannot be set beside a number from another.
  • Circularity distance rises with accuracy. The more a definition agrees with the consensus, the less it distinguishes itself from it. A rise in that measure is not necessarily an improvement.
  • The corpus tilts contemporary. A declared choice, and it affects every number here.
  • A definition cannot be falsified by a corpus that lacks what would falsify it. No paper bothers to write "an opinion column is not a work of art", so broad definitions are punished less than they deserve.
  • A quarter of the evidence cannot be re-checked from here. Seven of the scored papers — the pre-2010 classics — have no retrievable link, and they carry 98 of the 355 adjudicated cases. Their quotes were verified against stored text, but you cannot verify them from this site alone.

Who has done similar things

The move of treating a definition as a classifier and scoring it against cases is not our invention and we do not claim it. Bradley Allen (2023) did it for the concepts PLANET and WOMAN; psychiatry has compared rival definitions of the same disorder on one patient series since the 1970s; and natural-language processing has a similar genre for definitions of hate speech, where corpus-relativity of the score has already been published. What is new here: the cases are taken from what papers assert and are anchored to verbatim quotes — every competitor labels from surveys, crowds or knowledge bases — and the corpus is a parameter the user chooses.

How to reproduce it yourself

There is no server. Every number in the tool is computed in the browser from two files, and you can download them:
cases.jsonverdicts.jsonpapers.jsondefinitions.jsonmanifest.json

manifest.json carries the full schema — which files exist, what is in each, and the type of every field — written for AI agents as much as for people. The server returns access-control-allow-origin: *, so any other tool can pull the data directly, without permission and without a key. reference_scorer.py is a short dependency-free implementation that reproduces every published score; run it before trusting your own reading.

The acceptance test we set ourselves: given this URL alone, an agent that has never seen the project should be able to reproduce the whole table and get the same numbers. It did.
