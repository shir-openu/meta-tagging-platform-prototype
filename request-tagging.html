Why this page does not upload the file

GitHub Pages is static hosting; it can show this check but cannot privately receive a paper or create a payment authorization. The minimum direct-upload addition is one authenticated, rate-limited Vercel server route that issues a short-lived upload token, plus a private Blob store and deletion callback. No secret belongs in this page.

Minimum commercial hosting budget: $20/month base for Vercel Pro, including $20 of usage credit; Blob use is metered regionally after included credit. Vercel’s free Hobby plan is restricted to personal, non-commercial use. Manual email intake costs $0 incremental hosting.
